# Software Bill of Materials (SBOM)

This directory contains the Software Bill of Materials for the USD Content
Cache project.

The SBOM files are automatically generated by the CI/CD pipeline during the
build process. They provide a comprehensive inventory of all software
components, dependencies, and libraries included in the project's artifacts.
